# 隐私政策

**一句话：PixPeel 只在你的电脑上工作，不收集、不上传、不出售你的任何数据。**

## 留在本机的内容
- 截图和导入的图片都在本机内存里处理，不会上传。
- 你保存的元素写进你选的文件夹（默认：图片/PixPeel）。
- 设置保存在应用数据目录的一个小文件 `settings.json` 里（设置 → 关于 → 设置文件夹）。

## 联网请求（软件只会发出这两种）
1. **检查更新**（可选，默认开启，可在设置里关闭）：向 `api.github.com` 请求一次最新版本号。除了任何 HTTPS 请求都会带的内容（你的 IP 地址和“PixPeel”的 User-Agent），不发送个人信息或标识。
2. **AI 点选**（可选，只有你用到这个工具时）：第一次会从公共 CDN（jsdelivr / unpkg / huggingface.co 或 hf-mirror.com）下载一个开源小模型和运行库。你的图片**不会**被发送出去，推理在本机完成。

## 本地联动服务
开启“允许小剪动画读取素材库”后，软件会在 `127.0.0.1`（仅本机）上提供素材库，供“小剪动画”读取，其他设备访问不到。随时可以在设置里关掉。

## 权限
- **屏幕录制（macOS）** / 屏幕截取（Windows、Linux）：只在你按下快捷键时，用来拍一张屏幕画面。
- **开机自启**：默认关闭。

## 没有统计
没有遥测、没有追踪、没有广告、没有账号。

## 变更
本政策如有变化，会写进更新日志。
