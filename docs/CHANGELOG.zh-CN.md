# 更新日志

## 1.0.4

- **批量拆元素**：导入图片时可以一次选多张（按钮、拖拽都行），每张都自动拆开，所有元素汇总到一个列表里；点哪个元素就自动切到它来自的那张图。
- **拆元素页改成拼贴墙**：多张图统一缩放、按数量均分成网格铺在一张大画布上，当前操作的那块高亮，可以用滚轮缩放细看、拖动平移，整体一览再挑细节。
- **边缘平滑与补缺口（默认开启）**：导出时会自动补上边缘上的小缺口、填掉被完全包住的洞、把 alpha 过渡带抹平，边缘不再断断续续、也不会有台阶锯齿。纯本机算法，不联网、不加载模型；可在设置里关掉按原样输出。
- 左侧导航的 logo 改成按图标本身的几何重绘：橙色圆角方块里那圈白色虚线一直绕着中心圆点流动。
- 修复：切换界面语言后，SVG 画布还停留在上一种语言的文案。
- 修复：元素列表重画后滚动位置被弹回顶部（滑动后再点元素会跳回第一行），现在保持不动。
- 元素展示区改成更密的卡片网格，缩略图按侧栏宽度自动排布，空出来的空间被利用起来。

## 1.0.3

- 修复：设置里「检查更新」报 HTTP 301。GitHub 账号改过名，旧仓库路径会 301 重定向，现在改成正确路径，并且请求会自动跟随跳转。
- 修复：英文界面下素材库卡片的按钮显示不全（Board 被裁成 “oard”）。操作按钮挪到卡片底部并允许换行。
- 修复：SVG 画布的层级上移 / 下移不起作用（现在真的改 DOM 顺序，谁盖住谁会变）。
- 修复：SVG 画布里旋转是绕画布原点转的，改成绕图层自身中心转。
- 修复：SVG 画布中键拖不动画布。
- SVG 画布新增：左键框选多选、四角缩放 + 顶部圆点旋转手柄、Delete 批量删除、清空全部、方向键微调。
- 画板新增：左键框选多选（多选后可批量删除 / 缩放 / 旋转）、清空画布。中键拖动继续用来平移。
- 拆元素页的元素列表新增「清空」；素材库和 SVG 库新增「清空」（都是先标记、3 秒内可撤回，超时才真删）。
- AI 点选面板现在会写清楚当前用的是哪个模型、模型多大、什么配置才够用、有没有下好；可以一键下载、一键在量化版和浮点版之间切换。
- 左侧导航的 logo 外面加了一圈绕着中心圆点转的虚线。
- 图片可以直接拖到左侧导航按钮上：拖到「拆元素」就拆解、拖到「素材库」就存进去、拖到「画板」就加图层、拖到「SVG 库 / SVG 画布」就按 SVG 处理——和拖进右边工作区不是一回事。

## 1.0.2

- 新增「SVG 库」和「SVG 画布」两栏：分层 SVG 单独存放；SVG 画布里可以逐层显示/隐藏、移动、缩放、旋转、改透明度、删除，还能把某一层导成透明 PNG 存回素材库。接口约定见 docs/LINK-PROTOCOL.md。
- 删除改成「先不落地、3 秒内可撤回」：素材库、拆元素页、画板三处的删除都会弹出带进度条的撤回提示，超时才真的删。
- 元素列表改成卡片网格：缩略图按侧栏宽度自动变大变多，不再一条条挤着。
- 拆元素页新增「退出这张图片」的 ↩ 按钮，一键回到空白页。
- 支持从桌面把图片拖进任意一页：拆元素页就拆，画板就当素材，素材库直接存，SVG 库当 SVG 处理；拖到哪页，右上角就提示会怎么处理。
- 高清修复升级：Lanczos 放大 + 反锐化之外，增加迭代反投影（轮廓更实）和去边处理（白边黑边更少）。
- AI 点选的模型可以自己选：量化版（默认，约 15–40 MB，快、省内存）和浮点版（约 40–100 MB，精度略高、更吃内存），设置里能换；模型下好之后直接显示「AI 正在看」。
- 素材库里的元素多了一个「画板」按钮，复制一份到画板，素材本身留着可以反复用。
- 修复：Windows 上任务栏/通知显示成白图标（窗口图标改用多尺寸 ICO，并补建开始菜单快捷方式）。
- 修复：安装新版后开机自启还指向旧路径，开机拉不起程序；现在启动时会自动对齐到当前安装位置。

## 1.0.0

首个公开版本。

- 新增撤回 / 重做（Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y），拆元素页和画板都有。
- 拆元素页新增画面缩放：滚轮缩放、+ / − 、适应窗口、100%、空格拖动或鼠标中键平移；画板新增“缩放方式”菜单（含缩放到选中）。
- 设置里新增“键盘快捷键”一览，可随时查看全部快捷键。
- 素材库：显示每个素材的分辨率，低清素材标出“低清”，可单个或一键“高清修复”（纯本机放大 + 锐化，另存为 -HD 新图，原图保留）；设置里可开启“保存时自动修复小图”。
- 修复：套索 / 魔棒的“从当前减去”没有点选元素时，现在会作用到勾选或圈到的元素。

- 新增“画板”：用素材库里的元素或导入的图片拼图。可选画布大小（预设 / 自定义）、透明或纯色背景；素材拖入或点击添加，支持移动、缩放、旋转、删除、调整层级、滚轮缩放与平移；可导出 PNG / JPG，或存回素材库。

- 框选快捷键：屏幕变暗，拖动框选一块区域，自动拆开元素，挑想要的存成透明底 PNG。
- 点选提取快捷键：屏幕不变暗，鼠标移到哪个元素上就高亮，点一下直接存进素材库。
- 可导入图片（按钮、拖入、粘贴）用同样方式拆分。有点选 / 魔棒 / 套索 / 可选的 AI 点选，可导出分层 SVG。
- 素材库：点击复制到剪贴板、在文件夹中显示、删除（进回收站）。
- 可和“小剪动画”视频编辑器联动：保存的元素自动出现在它的贴图素材里。
- Windows 安装包（许可协议、安装路径、桌面快捷方式可选）；macOS（Intel / Apple 芯片）和 Linux 版本。
- 设置：语言（简体中文 / English）、主题（跟随系统 / 浅色 / 深色）、保存位置、快捷键、开机自启、关闭到托盘、系统通知、检查更新、更新日志、隐私政策。
- 点击“已保存”的系统通知可直接打开素材库。
