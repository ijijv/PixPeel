# 更新日志

## 1.0.1

- 配套的网页版动画编辑器「小剪动画」随安装包一起发布（`xiaoji-animation.html`，单文件，双击即用），Release 里可以直接下载。
- 修复：装到新位置或从开发版换成正式版后，开机自启还指向旧路径、开机拉不起程序。现在启动时会自动对齐到当前安装位置。
- 设置里“和小剪动画联动”的说明改成实际文件名，页签名也从“贴图”改成“贴纸”（和编辑器里一致）。

## 1.0.0

首个公开版本。

- 新增撤回 / 重做（Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y），拆元素页和画板都有。
- 拆元素页新增画面缩放：滚轮缩放、+ / − 、适应窗口、100%、空格拖动或鼠标中键平移；画板新增“缩放方式”菜单（含缩放到选中）。
- 设置里新增“键盘快捷键”一览，可随时查看全部快捷键。
- 素材库：显示每个素材的分辨率，低清素材标出“低清”，可单个或一键“高清修复”（纯本机放大 + 锐化，另存为 -HD 新图，原图保留）；设置里可开启“保存时自动修复小图”。
- 修复：套索 / 魔棒的“从当前减去”没有点选元素时，现在会作用到勾选或圈到的元素。

- 新增“画板”：用素材库里的元素或导入的图片拼图。可选画布大小（预设 / 自定义）、透明或纯色背景；素材拖入或点击添加，支持移动、缩放、旋转、删除、调整层级、滚轮缩放与平移；可导出 PNG / JPG，或存回素材库。

- 框选快捷键：屏幕变暗，拖动框选一块区域，自动拆开元素，挑想要的存成透明底 PNG。
- 点选提取快捷键：屏幕不变暗，鼠标移到哪个元素上就高亮，点一下直接存进素材库。
- 可导入图片（按钮、拖入、粘贴）用同样方式拆分。有点选 / 魔棒 / 套索 / 可选的 AI 点选，可导出分层 SVG。
- 素材库：点击复制到剪贴板、在文件夹中显示、删除（进回收站）。
- 可和“小剪动画”视频编辑器联动：保存的元素自动出现在它的贴图素材里。
- Windows 安装包（许可协议、安装路径、桌面快捷方式可选）；macOS（Intel / Apple 芯片）和 Linux 版本。
- 设置：语言（简体中文 / English）、主题（跟随系统 / 浅色 / 深色）、保存位置、快捷键、开机自启、关闭到托盘、系统通知、检查更新、更新日志、隐私政策。
- 点击“已保存”的系统通知可直接打开素材库。
